怪物森林 · 镇长循环

设计纲要 v1.1  ·  2026-06-04  ·  评审稿

一、解决什么问题

当前游戏功能丰富（物品/好感度/送礼/任务/反思 / 6 NPC），但缺一个让玩家"持续在意"的目标：

  • 跟 NPC 聊天 → 体验一次 LLM 智能就够了，三次重复
  • 刷好感度 → 触发 milestone 演出后没下游
  • 捡物品送礼 → 只为了刷好感度，自闭
  • 接任务 → 完成给物品，又喂回送礼循环

核心症结：缺少一根串起所有零件的主轴。LLM NPC 只被当作"会说话的物品交换机"，没用在该用的地方。

二、设计目标 & 反目标

要做不做
玩家有清晰长期目标：当镇长 → 维持权位 → 落选反扑 不写线性主线剧情
每个零件都接到目标上：affection = 选票，gifts = 拉票，quests = 竞选承诺 不靠美术演出撑（仅用现有 UI 风格扩展）
循环耐玩，不依赖一次性内容：对手轮换 / 搬家 / 危机随机 不引入战斗 / 数值堆叠
LLM 用在它擅长的事：动态台词、辩论反驳、立场生成 不让 LLM 决定数值（保留确定性）

三、玩家体验想象

第 3 天，上午 09:00。HUD 左上角声望榜：你 32%，对手苔老板 41%。还剩 4 天到投票。

走进面包店，看见苔老板正跟焰仔讲："那位旅人前几天给老咸送了酒，结果老咸醉了砸花圃……" —— 这是抹黑。你昨天偷听过老咸说"那花圃我自己撞的"，所以现在手里有反驳卡。

你可以：① 立刻打断澄清（消耗反驳卡，焰仔好感不变）② 不理会（声望 -3）③ 公开揭穿苔老板（高风险，赢了对手 -5，输了自己 -5）。

下午 14:00。小翠头顶冒出诉求气泡："草药地缺水了。" 接 = 加进承诺池（你已 4/5 条）；不接她下届会记仇。

晚上 22:00。所有 NPC 反思今天发生的事，重新评估明天投谁。你的声望涨到 36%，但苔老板涨到 44% —— 因为他今天在三个 NPC 面前演讲了。

第 6 天 · 辩论日。3 个 NPC 轮流提问，4 选项答题，对手 LLM 即时反驳。第 7 天 · 投票日，结果实时累计动画。3 票 vs 3 票 → 平局，你赢了你 affection 最高的那个 NPC 的关键一票，当选。

第 8 天 · 新任期 D1。权力点 +3。你指派焰仔去给老咸送修花圃的工具（消耗 1 点）；议会上发表施政演说（消耗 2 点）。但 D7 投票结算后，蓝旅搬走了（他对你 affection 只有 -5），公告横幅显示"蓝旅决定回去继续旅行"。同一天，新居民 桃桃 从邻镇搬来面包店附近——她对所有人 affection 都是 0，包括你。

新一周开始。对手换成焰仔了（苔老板上届当过，间隔保护），桃桃成了焰仔和你都想拉拢的中间票……

四、核心循环

[ 竞选期 ] [ 任期 ] 拜访拉票 → 兑现承诺 → 辩论 → 投票 → 当选演出 → 行使权力 → 处理危机 → 下次竞选 ↑ │ └─────── 落选 = 在野党（调查/搜集丑闻）→ 下届反扑 ──────────────────────────┘ │ 每届任期之间：搬家结算（0-2 走 / 0-2 来，新居民关系空白） ─────────────────┘

节奏：7 游戏日 = 1 任期。D1-D5 日常 / D6 辩论 / D7 投票。竞选期和任期共享同一时间轴，UI 切换。

五、八根支柱（关键机制）

1. 投票公式

每 NPC 对每候选人有 0-100 权重，每日 22:00 重算。affection 占 50 分（最重），承诺兑现率 20 分，辩论表现 10 分，近期事件 ±15 分，亲近圈忠诚 5 分。

2. 对手 AI（赛季轮换）

每届对手不同。从未当过的池子里抽，至少间隔 2 期重出。每日 1-2 个动作：拜访拉拢/散播怀疑/反承诺/演讲。落后激进，领先保守。立场由 LLM 基于其人设生成。

3. 承诺池（取舍）

NPC 头顶诉求气泡。接 = 入承诺池（上限 5 条）。兑现 = 加分；破诺 = 重罚。玩家被迫挑选，不能全收。

4. 任期权力点（有限性）

当选后每日 3 点。可消耗：指派 NPC 任务、召开议会、发布公告、私下协调关系。不累积，迫使每日决策。

5. 危机事件池（动态压力）

10-15 个机械模板，30%/日触发。例：面包店火灾 / 草药短缺 / 老咸闹事 / 财政赤字 / 神秘失踪。处理慢/不公 → 民意下滑。LLM 写具体台词。

6. 搬家系统（赛季新鲜感）

每届结算后：70% 走 1 人 / 20% 走 2 人 / 10% 不变。差人缘者优先走，挚友几乎不走。新居民 affection=0，第 1 季不能任对手。居民不会失忆，但镇上人在变。

7. 连任阶梯（成就驱动）

任期序号 N 越大，对手越聪明（增加动作/反偷听/联合围剿），危机越频繁，承诺池上限下降。称号：新晋镇长 / 二连霸 / 三朝元老 / 不倒翁 / 镇长传说。

8. 落选不重开

进入"在野党"模式：可调查现镇长、搜集失误证据、积累丑闻卡。下届辩论可打出，重创对手。affection 永不重置（合现实）。玩家永远有出路。

六、为什么这样设计 · 逻辑原理

体验问题对应机制
"和 NPC 聊天没意义"affection 直接折算 50% 选票权重，每次对话都在影响选举走向
"游戏太放松没驱动"7 天倒计时 + 对手实时刷分 + 危机随机触发 = 三重压力
"内容会重复消耗光"对手轮换 / 搬家流动 / LLM 生台词 → 每届都不一样
"养成系统脱离剧情"承诺池本身就是养成"我说话算话"的人设；连任阶梯就是养成路径
"做错事没办法挽回"落选不重开，在野党路线给重整旗鼓的空间
"做对了事没回报"权力点 / 称号 / 全 NPC 投票成就 / 民意所向加成
"剧情写不过来"机械骨架确定数值，LLM 只填台词；写一次模板用永远

七、LLM 用在哪

LLM 是这游戏最贵也最闪光的资产。它不该做的事：定数值、写一次性主线、决定胜负规则。它该做的事：

  • 对手每日动作的具体台词（例："苔老板今天去拜访了焰仔，他说……"）
  • 新对手就任时的"竞选纲领"生成（基于该 NPC 的 important_facts）
  • 辩论日的提问 + 反驳（NPC 提问、对手反驳玩家答案）
  • 危机事件的具体描述（机械触发"面包店火灾"，LLM 写"苔老板的炉子今早冒黑烟，火苗窜上房梁……"）
  • NPC 反思中的政治倾向（"今天玩家给我送了药，但他承诺的修水管还没做……"）
  • 新居民入镇剧情（基于其人设生成入场介绍）

所有 LLM 输出都被机械系统消化，最终落到数值（weight、affection、event_score）。LLM 永远填血肉，机械永远是骨架。

几乎不增加新概念，主要是把已有零件重新接线。

十、待用户继续拍板

  • 新对手立场是否需要玩家可见？（建议：偷听才能看到，符合"信息差"游戏体验）
  • 权力点滥用如何防（例如玩家天天派同一个 NPC 任务）？（建议：被指派次数 → 该 NPC 疲劳 -affection）
  • "民心所向"成就（单届 6/6 全票）是否过苛？是否调整为 5/6？
