# 开发日志

## 2026-07-26 · 镇长玩法打磨

### 时钟
- 单个游戏日改为 15 分钟：`world_clock.gd` `time_scale = 96`（1 实秒 ≈ 1.6 游戏分，任期 4 天 ≈ 60 分钟一局）。

### GM 调试指令
- `Ctrl+G`：玩家直升当前任期现任镇长（`debug_make_mayor`），便于测试镇务玩法。
- `Ctrl+M`：强制刷新一个镇务任务（`debug_spawn_mayor_task`）。

### 镇长玩法三处 Bug 修复
1. 任务 HUD 文字溢出：`quest_hud.gd` 面板高度改为按可见内容自适应（`_resize_panel`），镇务标签 `SIZE_EXPAND_FILL` 正确换行。
2. 「讲道理 / 威胁」两种安排方式无效：根因是选项文字用了 ASCII 方括号，被 BBCode 当标签解析破坏了 `[url]`。改用全角【】；拒绝后重开选项可换方式重试。
3. NPC 领任务后无表演、无反馈：根因是 busy 状态下 `_physics_process` 不跑 intent 移动，且对话关闭的 `clear_busy` 会清掉 intent。改为对话关闭后 NPC 以自发意图走到现场，到场才置 busy 表演。

### NPC 寻路优化（防卡死）
- `approach_for_intent` 改走 `PathNetwork` 路网航点队列，绕开湖/建筑。
- `_follow_intent` 增加卡死检测 + 总超时（14s）：卡住跳航点，无航点或超时则强制到达触发回调，NPC 永不楔住。
- `PathNetwork` 新增 `random_point` / `all_waypoint_positions`，用于取可达落点。

### 造谣（放话）交互优化
- 八卦栏按钮「放话」改名「造谣」。
- 点造谣进入造谣模式：输入框占位变「谣言：…」并聚焦，回车按 `request_rumor_spread` 发出（不再当普通聊天）；发完/按 Esc 退出模式。

### 镇务情境系统（任务刷新即布置）
- `main.gd` 监听 `mayor_task_state`，任务一刷新就在世界里布置情境：
  - 打扫：全村撒 3~4 处 🤢 脏物标记，NPC 逐个走到清扫。
  - 修下水道：随机路网点生 🔧 维修标记。
  - 治疗：随机指定一名病人 NPC，挂持久 🤒 并站定；治疗者赶到身边 💊，病人痊愈。
  - 制服酒鬼：目标挂持久 🍺 并站定，执行者赶到打斗。
- `Animal.set_status_effect / clear_status_effect`：持久状态图标 + 染色，期间屏蔽普通 emote。
- 表演结束统一 `_teardown_situation` 拆除标记/状态。

### 镇务失败与选情反馈
- 治疗任务不能派病人本人（前端 `_can_assign_here` 排除 target 本人）；后端 `assign` 拒绝时返回 `executor_id`+`error`，对话框显示失败原因并重开选项。
- 镇务完成后提示选情分变化：后端 assign 前后取玩家聚合选情分，随 `mayor_task_result` 下发；左上镇务 HUD 结果行追加「声望 X→Y (+N)」，并弹中央横幅（`election_hud.flash_mayor_toast`）。`勉强了事` 无明显变化也会明确提示，确认是否生效。

### 运维
