二、里程碑路线图

M1  ·  选举骨架可跑D1 → D5  ·  5 d

目标：玩家能完整跑 7 天周期 → 触发投票 → 看到结果 → 进入下一任期，骨架闭环。

包含任务：选举后端 / 对手 AI v1 简版 / 竞选 HUD / 投票日演出

✓ 验收：游戏能从 D1 跑到 D7，HUD 实时显示声望，D7 投票结果横幅正确，能进 D8 新一轮

M2  ·  玩家工具链D6 → D8  ·  3 d

目标：玩家有"明确该做的事"——接承诺、过辩论日，能对选举结果产生主动影响。

包含任务：承诺池系统（quests 重定位）/ 辩论日 UI & 后端

✓ 验收：玩家接 1 个承诺 → 兑现 → 该 NPC weight 涨；过 D6 辩论后 debate_score 显示正确

M3  ·  任期内容D9 → D10  ·  2 d

目标：玩家当选后有具体可玩内容，权力有稀缺性，危机有压力。

包含任务：任期权力点 v1 / 危机事件池（10 模板）

✓ 验收：任期内每日给 3 点权力可花；每天有 30% 概率触发危机，能选解决路径

M4  ·  系统活化D11 → D13  ·  3 d

目标：跑 2-3 任期能感受到差异，落选玩家有出路。

包含任务：赛季搬家系统 / 连任难度阶梯+称号 / 落选在野党模式

✓ 验收：第 2 任期对手不同；NPC 流动 ≥ 1 次；连任 N=2 时对手 buff 生效；落选能看到丑闻卡 UI

M5  ·  联调与平衡D14  ·  1 d

目标：玩家完整测试 2-3 任期不卡顿，数值校准。

包含任务：调参（投票公式权重 / 危机概率 / 权力点回报 / 称号门槛）/ Bug 修复 / 文案润色

✓ 验收：连续跑 21 个游戏日 0 报错，数值平衡（首期对手 vs 玩家差距 < 30%）

五、风险与对策

风险触发场景概率对策
LLM 调用超时/失败 对手台词、辩论反驳、危机文本 中 所有 LLM 用途都准备 fallback 文本（带 [备用] 标识），不阻塞主流程
weight 公式调不平衡 首期玩家被秒杀 / 永远赢 高 D14 留 1 整天调参；公式参数全集中常量；提供 debug 面板看 breakdown
D8 辩论 UI 工作量超预估 4 选项 + LLM 流式 + 评分动画交互复杂 中 第一版用纯文本无动画；视觉打磨延后到 M5
NPC 搬走破坏现有 schedule/任务依赖 承诺 NPC 被搬走 / 对手被搬走 中 搬走规则：当前对手不能搬；持有 pending 承诺的 NPC 降权（×0.4）
新 NPC 立绘缺失 npc_pool 配 3 人但没美术资源 低 用现有 char_X 资源池备用立绘，命名先用占位
玩家不知道怎么玩 新增机制太多，没有 onboarding 高 D14 加首次进入新机制时的横幅提示（"这是承诺池，最多 5 条..."）
测试覆盖不足 边界情形隐藏 bug 中 每个 M 结束前写 1-2 条自动化测试，沿用 tests/ 目录

六、验收指标（M5 结束时检查）

功能验收

  • ✅ 完整跑 3 任期不报错（含至少 1 次落选）
  • ✅ 至少有 1 次 NPC 搬家事件
  • ✅ 辩论日 4 选项功能完整
  • ✅ 任期内能用所有 4 种权力
  • ✅ 至少触发 5 种不同危机模板
  • ✅ 落选后能搜集到丑闻卡并在下届使用
  • ✅ 至少解锁 2 个称号

体验验收（主观判断）

  • ✅ 游戏 30 分钟后玩家清楚自己的目标
  • ✅ 投票日有紧张感（声望差距 < 15% 时有翻盘可能）
  • ✅ 第 2 任期能感受到与第 1 任期的差异（对手不同 / NPC 流动）
  • ✅ 落选不会让玩家想退出，反而想"我下届一定干掉他"

数值验收

  • weight 公式各子项贡献占比合理（affection 35-55%，其他每项 5-25%）
  • 新任期开局玩家与对手 weight 差距 ≤ 30%
  • "民心所向"（6/6 全票）连任不超过 1/4 玩家能拿到
  • 权力点用法分布均匀（4 行动各占 15-35%）

七、未来扩展（不在本计划内）

  • NPC 总池扩到 12+，每人完整 schedule + persona
  • 跨任期世界事件累积（如"森林神秘失踪悬案"贯穿多届）
  • 第二种结局路线（连续 5 届落选 → "森林流浪诗人"）
  • 多人/co-op 镇长（一人镇长一人副手）
  • 季节系统接入（春夏秋冬影响危机类型）
