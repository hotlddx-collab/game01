02
Why

设计目标：五条硬约束

现有触发类玩法（危机 / 情报 / 舆论）是"上层内容"，缺一个每天都在转的底座。职业系统来补。

🌲

① 世界观自洽

每个职业都能在当前小镇里被想象——不是凭空工种，而是接手镇上已有的某门营生。

♟️

② 有策略性

不是"点一下出钱"，而是有限资源下的押注与取舍：情报、风险回报、产能、时效。

🔄

③ 都有用、能循环

每职业需求与产出互为上下游，货与钱在镇里绕圈，任一行都不是死胡同。

🪙

④ 金钱=一般等价物

所有营生的产出经由森林币换算、交易、比较——统一的价值尺度。

⑤ 长期金钱出口：必须有一个"永远填不满的坑"把钱抽走，循环才不会因通胀而失速——本稿给出 4 个方案 + 推荐组合（见 P08）。

07
Keep Turning

每职业的完整闭环 · 保证"转得动"

对玩家所选的任一职业，四要素缺一不可，否则循环断点：

闭环四要素

  • 原料入口：≥2 条 —— 自采（免费费时）+ 购买（花钱省时）。
  • 加工产出：熟练度决定品质 / 成功率 / 售价上限。
  • 稳定买家：活 NPC 需求每日再生（吃饭、生病、装扮、施政）。
  • 钱回投：明确的花钱去处 —— 买更好原料 / 升级工坊 / 雇帮手。

防枯竭三闸（长期不失速）

  • 需求再生：NPC 每日/每周产生新需求，消费永不断档。
  • 原料再生：采集点定时刷新；稀缺料靠行商/邮差跨区补。
  • 行情调节：某货供多→价跌、稀缺→价涨，逼玩家换品类，防单一刷钱。
硬需求驱动社交：面包师要向渔夫买鱼、请邮差送货、生病找药师 —— 关系好 = 进货便宜 + 买家优先。于是"聊天 / 好感"从可有可无变成经济刚需。

08
Money Sink

长期金钱出口 · 4 方案

循环要有"永远填不满的坑"把钱抽走，否则钱越攒越多、边际归零、循环失速。

🏠

A · 房子装修/升级

优 动森式养成、有炫耀与归属感、软目标持久。

风险 与"竞选主轴"耦合弱，可能驱动力不足。

🗳️

B · 捐款换竞选积分

优 钱直接换选票权重/权力点，与主轴强耦合。

风险 易变 Pay-to-Win，破坏"靠人缘当选"的立意。

🏭

C · 店铺/工坊升级

优 钱→产能，经济内循环健康，前期天然去处。

风险 纯经济、缺情感目标，会有上限。

🏛️

D · 公共建设/施政基金

优 花钱办集市/修路→全镇加成 + 民意，钱变政绩。

风险 多为当选后才解锁，前期用不上。

推荐组合（分期释放）： 前期 C 工坊升级（钱有立即去处、放大产能）→ 中期 A 房子装修（软性长期目标、身份象征）→ 当选后 D 施政基金（钱→民意→连任）。 B 捐款仅作有限出口：设每日上限 + 边际递减，钱只能小幅助攻、决定权仍在人缘，避免 P2W。

09
Currency

金钱：一般等价物

森林币 (Forest Coin)

  • 唯一货币，统一衡量所有产出与服务的价值。
  • 玩家有钱包（MoneyStore，落库）；NPC 简化为"店铺报价 + 需求预算"，不做全镇钱包模拟，避免复杂度爆炸。
  • 收入来源：售卖成品 / 完成委托 / 售出情报图纸。
  • 支出去向：进原料 · 工坊升级 · 装修 · 施政基金 · 有限捐款。

行情（让钱活）

  • 每种货有基准价 ± 供需浮动：卖得多→价跌，稀缺→价涨。
  • 行情随事件波动：节庆面包涨、瘟疫药材涨、鱼汛期鱼便宜。
  • 行商的整个玩法就建立在读行情、跨区套利之上。
  • 行情是防枯竭与策略性的共同来源。
钱的三个使命：① 度量——把不同营生的产出可比较；② 润滑——让行业间交易发生；③ 沉淀——经长期出口抽走，维持循环张力。

Roadmap

落地路径 · MVP 先跑通最小循环

第一刀 · 验证抽象

做 🎣 渔夫（产原料）+ 🍞 面包师（吃原料） 这对上下游：

🎣 钓鱼读汛押点→ 🍞 收鱼做面包配方/炉容→ 🏘️ 卖居民口味/好感→ 🪙 森林币回投买料/升级

一次验证「采集→制作→消费→钱回流」整条链能否转起来。

通用框架（一套码撑 6 职业）

  • data/professions/*.json：原型/前辈/采点/配方/委托/策略参数/成长曲线。加职业 = 加 JSON。
  • 三原型（制作/服务/采集）共用「资源→动作→产出→售卖」抽象。
  • MoneyStore 钱包 + 行情表 + 商店/售卖 UI。
  • 活顾客引擎：购买由 情报匹配 + 好感 + 需求 + 口碑 驱动 → 喂选举声望。
依赖顺序：① 金钱+商店系统（下一份细化稿）→ ② 渔夫+面包师垂直切片 → ③ 行情/口碑 → ④ 其余 4 职按 JSON 扩 → ⑤ 长期出口（C→A→D）逐步接入。

Decisions

待你拍板的分叉点

1 · 职业是否可转行？

建议开局选一门专精，后期花钱/达成条件可转行体验其他行业（增加重玩性）。

2 · NPC 要不要真实钱包？

建议先"玩家钱包 + NPC 需求预算"，不做全镇钱包模拟；验证后再考虑。

3 · 长期出口组合？

推荐 C→A→D 分期，B 捐款设上限。是否采纳？

4 · MVP 组合？

推荐 渔夫 + 面包师。若想先验证经济博弈，可换 面包师 + 行商。
