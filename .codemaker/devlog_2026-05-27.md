# 开发日志 2026-05-27

## 本次会话完成内容

### P2 全部完成

**P2-1 反思机制**
- NPC 每日 22:00 自动回顾当日记忆，LLM 生成 3-5 条结构化反思（JSON 格式，含 importance 1-10 + tags）
- 新表 `reflections(animal_id, game_day, content, importance, tags)`
- 反思注入对话 prompt `【你最近的想法】` 块，NPC 有"持续想法"感
- 客户端 WorldClock.hour_changed 在 22:00 自动发 `time_tick` 到后端触发
- debug endpoint：`POST /debug/reflect/{animal_id}/{day}`

**P2-C importance 自动评分**
- `fact_extractor.py` 关键词表扩充 ~30 项（情感词/互动词/承诺词）
- 新增 `importance_for_gift(delta)` 4 档映射
- agent.py 所有 `memory.add` 改用 `estimate_importance(text, base=N)`
- 分布：普通闲聊 3-4 / 礼物 6-8 / 名字/承诺/吵架 7-9

**P2-B 反思驱动 NPC 自发行为**
- 反思 `tags=["intent"]` 自动写 `animal_intents` 表（含 target_id + activate_hour）
- 每日 `time_tick` 激活到期意图 → 推 `npc_intent` WS 包
- 客户端：initiator NPC 走向 target NPC（`approach_for_intent` + Callable 到达回调）
- 到达后双方面对面触发 npc_chat

**P2-2a 旧记忆归档**
- `MemoryStore.cleanup_old()`：保留最近 60 条 + importance≥5 的，删除其余
- 每次反思后自动调用

**P2-2b 反思 → player impression**
- 反思里 tags=player + importance≥6 → 写入 `player_profile["impression"]`
- `_build_player_profile_block()` 注入 impression 字段
- NPC 在对话里能体现"记得你是个什么样的人"

### 礼物系统重大优化

**NPC → 玩家送礼（B：love 升级触发）**
- 好感度首次升到 love → NPC 自动赠送 `signature_gift`（每人只一次）
- 6 个 NPC 各有专属礼物：苔→饼干 / 焰→信件 / 翠→草药茶 / 老咸→罗盘 / 煊→萤石 / 蓝→地图碎片
- 对话框显示金色 🎁 提示，物品自动入背包

**对话驱动 intent（答应去找某人）**
- reply() LLM 输出 JSON：`{"text": "...", "intent": {"target_id": "...", "summary": "...", "agreed": true}}`
- 答应后写 `animal_intents`，次日激活 NPC 真的走过去
- 对话框显示 📅 提示

**玩家索要礼物系统**
- LLM 识别"索要"信号 → 后端规则裁决（不依赖 LLM）
- love: CD=1天/不扣分 | like: CD=2天/-3 | warm: CD=3天/-5 | 其他: 拒绝
- 拒绝时给明确反馈（关系不够 / CD 未到）

**gift_guard 重生成**
- 15 个送礼词汇（送你/给你/要不要尝尝/来一口等）触发自动重生成
- 系统规则 11-12：严禁口头送礼 + 世界一致性（已知物品/地点列表）
