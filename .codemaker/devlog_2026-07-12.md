# 开发日志 2026-07-12

## 概览

本次围绕「让游戏不无聊」的基础玩法推进，完成三大块（均为高性价比、复用现有社会引擎）：

1. **危机调解 · 软性截止 + 自然触发**（承接上次）
2. **心情系统（C）**：每只 NPC 的动态情绪，影响语气 + 头顶常驻表情
3. **八卦活社会（A）**：话题生成 → NPC 相遇传播变味 → 传到当事人后果 → 玩家打听/放话/辟谣

设计决策：一度设计「职业系统」，但评估开发性价比过低（资源循环强行自洽易出常识谬误）后放弃，转向复用已有的反思/意图/npc_chat/world_events/偷听引擎——「活社会 + 心情」约 80% 底座已存在，只需让它可见、可变、玩家可干预。

## 二、心情系统（C）

### 后端
- **`mood` 表**（db.py）：`animal_id / value[-100,100] / updated_at / last_day`。
- **`mood.py` MoodStore**：
  - 单标量 valence，惰性衰减——读取时按经过的游戏日向 0 收敛（`DECAY_PER_DAY=12`）。
  - 5 档：兴奋😄 / 开心😊 / 平静😐 / 低落😔 / 烦躁😠。
  - `get / snapshot / adjust`（先衰减再叠加）。
- **事件钩子**（main.py）：招呼/聊天/送礼/危机结算 → 由好感 delta + 类型折算推动心情，回包带当前心情快照。

### prompt + 前端
- `agent.py` `_build_mood_block()`：非平静时注入语气提示（烦躁→说话冲、低落→话少…），reply 包携带 `mood`。
- `animal.tscn` 加 `MoodLabel`（名字右侧头顶），`animal.gd set_mood()`——平静隐藏、其余档位常驻。
- `agent_client.gd` `mood_changed` 信号 + 解析；`main.gd` 连信号驱动对应 NPC。
- 已知限制：NPC 初次生成默认平静（隐藏），首次互动后表情才常驻（初始快照广播留待后续）。

## 三、八卦活社会（A）

### 数据模型（db.py）
- **`rumor`**：`subject_id`（主角，可为 `player`）/ `sentiment`（praise 褒 / smear 贬 / neutral）/ `truth`（真伪）/ `heat`（热度 0-100）/ `content` / `origin` / `status`（active/faded/debunked）。
- **`rumor_knowledge`**：谁知道哪条 + ta 口中的版本（`version`）/ `hops` / `told_count`（防刷）。

### `rumor.py`：RumorStore + RumorManager
- **生成** `generate()`：玩家显著言行 → 以玩家为主角的话题，见证 NPC 成初始知情者；auto 来源当日「同主角同情感」去重加温。
- **传播 + 变味** `propagate()`：NPC 相遇闲聊时 `pick_gossip_for` 挑最热话题注入 speaker，闲聊里带出来；listener 学到后 LLM 按**性格 + 心情**改写成 ta 的版本（变味），热度 +6，`told_count` 上限 2。
- **每日降温** `decay_daily()`：热度 -8，冷透 → faded。

### 生成触发（main.py）
- 送大礼（gift delta ≥4）→ praise；送不待见的东西（≤-2）→ smear。
- 聊天顶撞（好感 ≤-3）→ smear。
- 危机结算：受影响 NPC 好感总和 >0 → praise / <0 → smear。

### 传播 + 后果（main.py）
- `_handle_npc_chat`：注入 gossip → 跑 npc_chat → 会后 `propagate` 到 listener。
- `_apply_rumor_consequence`：话题传到当事人耳朵 → 心情±、好感±；若源自玩家的坏话被当事人**记恨**（好感 -4）。
- 玩家主角话题进 `world_events` → 喂反思 → 影响投票。

### 玩家动作（协议 + 后端 + 前端）
- 协议：`rumor_inquire` / `rumor_spread` / `rumor_debunk`，回 `rumor_reply`。
- 后端三 handler：打听（NPC 口吻透露最热话题）/ 放话（灌入新话题 + NPC 当面反应）/ 辟谣（-35 热度，冷透标 debunked）。
- `agent.py` 加 `_build_gossip_block`（闲聊时提示 NPC 自然带出八卦、允许走样）。
- 前端：对话框加「🗣 八卦」按钮 → 展开动作栏（打听/放话/辟谣）；`dialog.tscn` 加 `GossipButton/GossipBar` + `dialog_ui.gd` 逻辑（记最近打听到的 rumor_id 供辟谣）。
